📚 完整操作指南（從零開始）
步驟 1️⃣：建立或選擇 Google Cloud 專案
  1. 前往 Google Cloud Console
  2. 在頂部導覽列，點擊專案下拉選單
  3. 如果沒有專案：點擊「新增專案」
    • 輸入專案名稱（例如：emotion-detector）
    • 點擊「建立」
    • 等待專案建立完成（約 10-30 秒）
  4. 如果已有專案：選擇要使用的專案
步驟 2️⃣：啟用 Cloud Vision API
  1. 點擊這個連結：Cloud Vision API
  2. 確認頂部顯示的是正確的專案名稱
  3. 點擊藍色的「啟用」按鈕
  4. 等待啟用完成（約 5-10 秒）
  5. 成功後會顯示「API 已啟用」
步驟 3️⃣：建立 API 金鑰
  1. 點擊左側選單「憑證」（或直接點 這裡）
  2. 點擊頂部「+ 建立憑證」按鈕
  3. 選擇「API 金鑰」
  4. 會彈出視窗顯示新建立的 API Key，先複製並儲存它
  5. 點擊「編輯 API 金鑰」或「限制金鑰」
步驟 4️⃣：設定 API 金鑰限制
  1. 在「應用程式限制」區域：
    • 選擇「無」（測試時最簡單）
    • 或選擇「HTTP referrer (網站)」然後輸入 *
  2. 在「API 限制」區域：
    • 建議：先選擇「不限制金鑰」（測試用）
    • 或：選擇「限制金鑰」→ 在下拉選單搜尋並勾選「Cloud Vision API」
  3. 點擊底部「儲存」按鈕
  4. 重要：等待 1-2 分鐘讓設定生效
步驟 5️⃣：使用 API Key
  1. 複製你的 API Key
  2. 貼到上方的「Google Vision API Key」輸入框
  3. 點擊「開始偵測」測試
  4. 如果遇到錯誤，勾選「顯示詳細除錯資訊」查看問題
⚠️ 常見問題：
  • 找不到專案？ 確認已登入正確的 Google 帳號
  • 無法啟用 API？ 可能需要啟用計費（但有免費額度 1,000 次/月）
  • 權限不足？ 確認你是專案的擁有者或編輯者
  • 還是失敗？ 嘗試建立全新的專案和 API Key

🛠️ 疑難排解指南

  • 權限不足錯誤？ API Key 限制設定不正確，請設定為「無限制」或允許所有 referrer
  • 未偵測到臉部？ 確保臉部完整出現在畫面中央，距離 30-100 公分
  • 光線問題？ 需要充足且均勻的光線，避免逆光或陰影
  • 配額用完？ 免費額度 1,000 次/月，前往 Google Cloud Console 檢查使用量
  • 相機無法啟動？ 確認瀏覽器權限，在 HTTPS 環境下使用
  • API 未啟用？ 前往 Google Cloud Console 啟用 Cloud Vision API
